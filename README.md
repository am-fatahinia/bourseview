# بورس‌ویو — سامانه تحلیل بازار بورس ایران با داده‌ی واقعی

سامانه‌ی وب برای تحلیل بنیادی بازار بورس ایران با اتصال مستقیم به API رسمی **TSETMC** (مدیریت فناوری بورس تهران). تمام داده‌ها — قیمت‌ها، شاخص‌ها، صندوق‌ها، نسبت‌های مالی — به‌صورت زنده از منبع رسمی دریافت می‌شوند.

![بورس‌ویو](https://img.shields.io/badge/TSETMC-Live%20API-00d09c) ![Python](https://img.shields.io/badge/Python-3.8+-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## ✨ امکانات

- 📊 **دیده‌بان لحظه‌ای بازار**: ۵۸۱+ سهم بورس و فرابورس با قیمت، درصد تغییر، حجم، ارزش معاملات، P/E و EPS
- 📈 **شاخص‌های زنده**: شاخص کل (TEDPIX)، هم‌وزن، آزاد شناور، صنعت و ۵۳ شاخص دیگر
- 🪙 **صندوق‌های قابل معامله (ETF)**: ۲۱۸ صندوق با NAV، بازدهی ۱/۷/۳۰/۹۰/۳۶۵ روزه و ترکیب دارایی‌ها
- 🏭 **گروه‌های صنعت**: ۴۲ شاخص صنفی (بانک‌ها، پالایش، فلزات، دارویی و...)
- 🔍 **جستجوی سریع نماد**: با تایپ چند حرف، بین همه‌ی نمادها جستجو کنید
- 📋 **صفحهٔ تحلیل سهم**: قیمت، P/E، EPS، حدود روز، تعداد معاملات، حجم و ارزش معاملات
- 📊 **نمودار قیمت لحظه‌ای**: نمودار درون‌روزانه با داده‌های زنده TSETMC (۴۰۸۲+ نقطه برای هر سهم)
- 🎯 **فیلتر پیشرفته**: غربالگری روی ۶ شاخص مالی با شرط‌های ترکیبی
- 🔔 **هشدار قیمت**: ثبت هشدار برای عبور قیمت از حد مشخص
- 💎 **محاسبه‌گر ارزش ذاتی (DCF)**: محاسبهٔ ارزش منصفانهٔ سهم با مدل تنزیل جریان نقدی
- ⭐ **نشان‌شدگی و داشبورد شخصی**: لیست سهم‌های مورد علاقه و داشبورد اختصاصی
- 🔄 **به‌روزرسانی خودکار**: هر ۳۰ ثانیه داده‌های بازار به‌روزرسانی می‌شوند
- 🛡️ **Fallback هوشمند**: در صورت قطع موقت API، آخرین دادهٔ موفق نمایش داده می‌شود

## 🚀 نصب و اجرا

### پیش‌نیازها

- **Python 3.8 یا بالاتر** ([python.org](https://python.org/downloads/))
  - ⚠️ **ویندوز**: هنگام نصب، گزینهٔ **"Add Python to PATH"** را حتماً فعال کنید.
- اتصال اینترنت (برای دسترسی به API بورس)

### روش ۱: اجرای سریع با launcher کراس‌پلتفرم (توصیه می‌شود)

این روش روی همه‌ی سیستم‌عامل‌ها (ویندوز، لینوکس، مک) کار می‌کند:

```bash
# وارد پوشهٔ پروژه شوید
cd bourseview

# اجرای launcher (مرورگر به‌طور خودکار باز می‌شود)
python launch.py
```

**گزینه‌های اضافی launcher:**

```bash
python launch.py --port 8080       # استفاده از پورت سفارشی
python launch.py --no-browser       # مرورگر را باز نکن
python launch.py --install-only     # فقط وابستگی‌ها را نصب کن
```

### روش ۲: اجرای سریع با اسکریپت بومی سیستم‌عامل

#### 🪟 ویندوز

```cmd
:: دو بار کلیک روی فایل run.bat
:: یا از Command Prompt:
cd bourseview
run.bat
```

#### 🐧 لینوکس / 🍎 مک

```bash
cd bourseview
./run.sh
```

اسکریپت به‌طور خودکار:
1. وابستگی‌های Python (flask, requests) را نصب می‌کند
2. پروکسی محلی را روی پورت `5000` اجرا می‌کند
3. مرورگر پیش‌فرض را به آدرس `http://127.0.0.1:5000` باز می‌کند

### روش ۳: اجرای دستی

```bash
# ۱. وارد پوشهٔ پروژه شوید
cd bourseview

# ۲. وابستگی‌ها را نصب کنید
pip install -r requirements.txt
# یا
pip install flask requests

# ۳. پروکسی را اجرا کنید
python proxy.py

# ۴. مرورگر را باز کنید
# آدرس: http://127.0.0.1:5000
```

### روش ۴: اجرا با پورت سفارشی

```bash
# روی همه‌ی سیستم‌عامل‌ها
PORT=8080 python proxy.py     # لینوکس/مک
set PORT=8080 && python proxy.py    # ویندوز (CMD)
$env:PORT=8080; python proxy.py     # ویندوز (PowerShell)
# یا
python launch.py --port 8080
```

### چرا به پروکسی نیاز داریم؟

سامانهٔ رسمی TSETMC برای جلوگیری از misuse، هدر CORS را روی پاسخ‌های JSON خود قرار نمی‌دهد. به همین دلیل مرورگر نمی‌تواند مستقیماً به آن وصل شود. پروکسی محلی این مشکل را با:

1. افزودن هدر صحیح `Referer: https://www.tsetmc.com/` به درخواست‌ها
2. افزودن هدر `Access-Control-Allow-Origin: *` به پاسخ‌ها
3. کش درون‌حافظه‌ای برای کاهش بار روی TSETMC
4. Fallback به آخرین دادهٔ موفق در صورت قطع موقت API

حل می‌کند.

## 📡 API پروکسی

پروکسی محلی این endpointها را در اختیار frontend قرار می‌دهد:

| Endpoint | توضیح | TTL کش |
|---|---|---|
| `GET /api/health` | بررسی سلامت پروکسی | بدون کش |
| `GET /api/marketwatch` | همه‌ی سهام بورس و فرابورس | ۳۰ ثانیه |
| `GET /api/indices` | همه‌ی شاخص‌ها + شاخص‌های اصلی | ۳۰ ثانیه |
| `GET /api/sectors` | ۴۲ گروه صنعت | ۶۰ ثانیه |
| `GET /api/funds?types=3,4,5` | صندوق‌های قابل معامله | ۱۲۰ ثانیه |
| `GET /api/stock/{ins_code}` | جزئیات کامل یک سهم | ۳۰ ثانیه |
| `GET /api/stock/{ins_code}/intraday` | داده‌ی نمودار درون‌روزانه | ۶۰ ثانیه |
| `GET /api/search?q={query}` | جستجوی نماد | ۳۰۰ ثانیه |

## ⚠️ محدودیت‌ها

- این نسخه از طریق پروکسی محلی اجرا می‌شود؛ برای استفادهٔ آنلاین باید روی سرور با IP عمومی دیپلوی کنید.
- داده‌های **صورت‌های مالی ۵ دوره** (کدال) و **تقویم مجامع** هنوز پیاده‌سازی نشده‌اند (در نسخهٔ آینده).
- در صورت قطع اینترنت یا فیلترینگ TSETMC، سامانه به حالت Fallback می‌رود و آخرین دادهٔ موفق را نمایش می‌دهد.
- پروکسی برای توسعه بهینه شده است؛ برای production از یک WSGI server مانند `gunicorn` استفاده کنید:
  ```bash
  pip install gunicorn
  gunicorn -w 4 -b 0.0.0.0:5000 proxy:app
  ```

## 🔧 عیب‌یابی

### 🪟 مشکلات خاص ویندوز

#### مشکل مهم: خطای «Access is denied» هنگام اجرای Python

اگر هنگام اجرای `run.bat` این خطا را دیدید:

```
Unable to create process using
'"C:\Program Files\WindowsApps\PythonSoftwareFoundation.PythonManager_...python3.exe"':
Access is denied.
```

**دلیل**: Python شما از **Microsoft Store** نصب شده است که در پوشهٔ محافظت‌شدهٔ `WindowsApps` قرار دارد و اجازهٔ اجرای اسکریپت‌های خارجی را نمی‌دهد.

**راه‌حل (۳۰ ثانیه):**

۱. به لینک زیر بروید: [https://www.python.org/downloads/](https://www.python.org/downloads/)
۲. دکمهٔ سبز **«Download Python 3.12»** را بزنید
۳. فایل نصب را اجرا کنید و در صفحهٔ اول تیک این گزینه را **حتماً** بزنید:

   ```
   ☑ Add Python to PATH    ← خیلی مهم!
   ```

۴. پس از اتمام نصب، **CMD یا PowerShell را ببندید و دوباره باز کنید**، سپس `run.bat` را دوباره اجرا کنید.

**نکته**: برای بررسی اینکه Python از کدام منبع نصب شده، در CMD این دستور را اجرا کنید:

```cmd
where python
```

- اگر مسیر با `C:\Users\...\AppData\Local\Programs\Python\...` شروع شود → از python.org نصب شده ✓ (درست)
- اگر مسیر با `C:\Program Files\WindowsApps\...` یا `C:\Users\...\AppData\Local\Microsoft\WindowsApps\...` شروع شود → از Microsoft Store است ✗ (مشکل‌ساز)

#### مشکل: «python» به‌عنوان دستور شناخته نشد
- هنگام نصب Python، گزینهٔ **"Add Python to PATH"** را فعال نکرده‌اید.
- راه‌حل: دوباره نصب کنید و این گزینه را فعال کنید، یا از `py` به جای `python` استفاده کنید:
  ```cmd
  py proxy.py
  ```

#### مشکل: خطای Encoding در Command Prompt
- برای رفع مشکل کاراکترهای فارسی در CMD:
  ```cmd
  chcp 65001
  ```
- یا از PowerShell استفاده کنید که پشتیبانی بهتری از UTF-8 دارد.
- فایل `run.bat` به‌طور عمدی فقط از کاراکترهای ASCII استفاده می‌کند تا این مشکل پیش نیاید؛ همهٔ پیام‌های فارسی داخل Python چاپ می‌شوند.

#### مشکل: پورت ۵۰۰۰ اشغال است
```cmd
:: دیدن پراسس‌های روی پورت 5000
netstat -ano | findstr :5000
:: متوقف کردن پراسس (PID را از دستور بالا بگیرید)
taskkill /PID <PID> /F
```

### 🐧 مشکلات خاص لینوکس / مک

#### مشکل: «Permission denied» روی run.sh
```bash
chmod +x run.sh
./run.sh
```

#### مشکل: پورت ۵۰۰۰ اشغال است
```bash
lsof -i :5000
kill -9 <PID>
```

### مشکلات عمومی

#### مشکل: «Connection refused» یا صفحهٔ خالی
- مطمئن شوید پروکسی در حال اجرا است: `python proxy.py`
- پورت ۵۰۰۰ اشغال نباشد: `lsof -i :5000` (لینوکس/مک) یا `netstat -ano | findstr :5000` (ویندوز)
- اگر پورت اشغال است: `python launch.py --port 8080`

### مشکل: داده‌ها نمایش داده نمی‌شوند
- اینترنت را بررسی کنید (TSETMC باید قابل دسترس باشد)
- لاگ پروکسی را ببینید: خطاهای TSETMC در ترمینال چاپ می‌شوند
- کش را پاک کنید: کش درون‌حافظه‌ای است، با ری‌استارت پروکسی پاک می‌شود

### مشکل: «خطای CORS» در کنسول مرورگر
- مطمئن شوید فایل HTML از طریق `http://127.0.0.1:5000` باز می‌شود، نه با `file://`

### مشکل: بازار را «بسته» نشان می‌دهد در حالی که باز است
- timezone سیستم خود را بررسی کنید (ایران UTC+3:30)
- نمایش وضعیت بازار تقریبی است؛ داده‌ها واقعی هستند
